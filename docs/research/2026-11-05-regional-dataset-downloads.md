# Regional dataset download notes: Rajshahi and Chattogram

Verified against the linked NASA and USGS product pages on 2026-11-05. These are acquisition instructions, not evidence that matching granules were downloaded or that either pilot has adequate coverage. Define the actual pilot polygons and analysis dates first; district, division and city boundaries are different. Search each polygon separately, inspect footprint intersections, and retain the exact polygon, UTC date window, collection version, granule IDs, download date and processing parameters. Do not infer local coverage from global collection coverage. For raster tiles, download every intersecting tile and clip after mosaicking; for global daily grids, subset spatially if the service offers it. Use an initial common analysis window after 2019-04-04 only if useful to the project, and adjust for the GEDI gap and availability below.

## Access workflow

Create a free [NASA Earthdata Login](https://urs.earthdata.nasa.gov/) and use [Earthdata Search](https://search.earthdata.nasa.gov/search) to find the exact collection and version, set the pilot polygon and dates, inspect granules, and select Download or available customization. Approve a DAAC application when the login prompts for authorization; keep credentials out of the repository. Subsetting and format conversion depend on the collection and service: inspect the actual order options rather than assuming all products offer them. For [EarthExplorer](https://earthexplorer.usgs.gov/), use a USGS account and its own download workflow. NASA's [SMAP access guidance](https://nsidc.org/data/spl3smp_e/versions/6) confirms Earthdata Login is required; [USGS](https://www.usgs.gov/landsat-missions/landsat-data-access) documents EarthExplorer and bulk access.

## Rainfall: GPM IMERG Final Daily V07

Search **GPM_3IMERGDF**, version **07**, in Earthdata Search or the [GES DISC product page](https://disc.gsfc.nasa.gov/datasets/GPM_3IMERGDF_07/summary?keywords=imerg); select both pilot polygons and the desired dates, then use download or the advertised OPeNDAP link. The [CMR directory](https://cmr.earthdata.nasa.gov/search/site/collections/directory/GES_DISC/gov.nasa.eosdis) identifies it as a daily 0.1° collection; [granule listings](https://cmr.earthdata.nasa.gov/virtual-directory/collections/C2723754864-GES_DISC/temporal/2025/07/03) show NetCDF4 (`.nc4`). Keep `precipitation`, its valid-observation count if available, coordinates and time. The variable is a **daily mean rate in mm/day**, computed from valid half-hourly samples, not an unconditional sum; retain counts when assessing incomplete days. Final data have a latency of up to four months plus approximately a day, so this is not a live rainfall feed. [Source](https://disc.gsfc.nasa.gov/datasets/GPM_3IMERGDF_07/summary?keywords=imerg).

## Soil moisture: SMAP enhanced L3 V6

Search **SPL3SMP_E**, version **6**, at [NSIDC](https://nsidc.org/data/spl3smp_e/versions/6) or Earthdata Search. Choose global-grid granules, the desired daily dates and each polygon; select Harmony customization if offered or download the HDF5 originals. Preserve the AM/PM soil moisture retrievals and their corresponding retrieval quality flags, coordinates and timestamps; consult the linked product user guide for exact group paths and flag interpretation before filtering. It is a daily composite on a 9 km EASE-Grid, available from 2015-03-31, and is surface soil moisture rather than a field-scale measurement. NSIDC confirms [Harmony customization for this collection](https://nsidc.org/data/user-resources/data-announcements/user-notice-nasa-earthdata-harmony-data-transformation-services-now-available-smap-l2-l4-data-sets).

## Vegetation: MODIS MOD13Q1 V061

Search **MOD13Q1**, version **061**, via [Earthdata Search](https://search.earthdata.nasa.gov/search?q=MOD13Q1); select intersecting sinusoidal tiles and 16-day composites for each pilot and period. Download native HDF granules, or use a currently offered spatial/layer subset and output format if the service supports it. Retain NDVI, EVI if needed, vegetation-index quality and pixel acquisition day, plus coordinates and metadata for scale/fill values. The Terra product is 250 m with 16-day compositing; the [NASA collection metadata](https://git.earthdata.nasa.gov/projects/VISLABS/repos/metadata-mapping/browse/umm/visualization/data/tiles/input/gibs.earthdata.nasa.gov/layer-metadata/v1.0/MODIS_Terra_L3_EVI_16Day.json?at=20c83a34f6b&until=20c83a34f6b10a39d37d66147176b542bf9f7606) identifies V061, EVI and its resolution. Apply the file's scale and quality rules before interpreting a composite as a time series.

## Landsat 8/9 Collection 2 Level-2

In [EarthExplorer](https://earthexplorer.usgs.gov/), enter a polygon and dates, choose **Landsat → Landsat Collection 2 Level-2 → Landsat 8-9**, and inspect each scene's footprint, cloud cover and product availability before download. USGS documents this exact selection in its [Level-2 guide](https://www.usgs.gov/landsat-missions/landsat-collection-2-level-2-science-products). Keep surface reflectance bands SR_B4 and SR_B5 for NDVI, `QA_PIXEL`, `QA_RADSAT`, metadata, and `ST_B10` plus `ST_QA` if surface temperature is needed. Scene products are GeoTIFFs with metadata; select scenes with a valid surface-temperature product when temperature is required, since some Level-2 scenes only contain surface reflectance. Apply USGS scale/offset and QA definitions. Landsat 8 begins in 2013 and Landsat 9 in 2021; cloud cover and actual scenes determine usable observations. [USGS reflectance](https://www.usgs.gov/landsat-missions/landsat-collection-2-surface-reflectance), [temperature](https://www.usgs.gov/landsat-missions/landsat-collection-2-surface-temperature).

## Land surface temperature: ECOSTRESS LSTE V003

Search **ECO_L2G_LSTE**, version **003**, in Earthdata Search for each pilot polygon and period. This is the confirmed gridded V3 collection, distributed as HDF5, with `LST`, `QC`, `cloud_mask`, `water_mask`, `LST_Err` and metadata; its catalog specifies LST scale 0.02 K and fill 0. The [NASA catalog](https://doi.org/10.5067/ECOSTRESS/ECO_L2G_LSTE.003) identifies approximately 70 m nominal resolution, variable acquisition timing, and historical acquisition gaps. Inspect each observation's acquisition time and quality; it is not a regular daily series. The same catalog says V3 tiled **ECO_L2T_LSTE** is offered as cloud-optimized GeoTIFFs, but availability of matching V3 tiles in the pilot AOIs has not been verified. V3 has no non-gridded L2 LSTE swath HDF5 product.

## Regional water storage: JPL GRACE/GRACE-FO mascon

At [PO.DAAC](https://podaac.jpl.nasa.gov/dataset/TELLUS_GRAC-GRFO_MASCON_GRID_RL06.3_V4), select **TELLUS_GRAC-GRFO_MASCON_GRID_RL06.3_V4**, browse/download the single global NetCDF4 file or use the linked PO.DAAC subscriber. Preserve `lwe_thickness` in cm, `uncertainty`, `mascon_ID`, coordinates, `time` and `time_bounds`; subset the months and region locally. These are monthly water-storage anomalies relative to a time mean, not direct groundwater levels. The displayed grid does not imply independent field-scale measurements; use the product's mascon/support and coastal handling guidance, especially for Chattogram, and do not claim distinct village-level observations. Record the actual available months, including mission gaps. Consult the [JPL mascon guidance](https://grace.jpl.nasa.gov/data/get-data/jpl_global_mascons/) for scaling and coastal alternatives.

## Terrain: SRTMGL1 V003

Search **SRTMGL1**, version **003**, in Earthdata Search using the two pilot polygons, or open its [product DOI](https://doi.org/10.5067/MEASURES/SRTM/SRTMGL1.003). Download intersecting elevation tiles, including all tiles crossed by the polygons, then mosaic and clip. Native delivery includes zipped `.hgt` elevation rasters; retain elevation and tile metadata. It is a static 1-arc-second DEM, not a time series; consult the [NASA SRTM guide](https://www.earthdata.nasa.gov/s3fs-public/2025-05/SRTM_Quick_Guide.pdf) for coverage and void caveats. LP DAAC has migrated files to cloud storage; use current Earthdata Search links rather than assuming legacy Data Pool URLs still work. [LP DAAC migration guidance](https://forum.earthdata.nasa.gov/viewtopic.php?sid=e0c54e512fb47bdb74c62b92ebaa7d19&t=7608).

## Biomass: GEDI L4A V3

Use [ORNL DAAC dataset 2508](https://daac.ornl.gov/cgi-bin/dsviewer.pl?ds_id=2508) or search **GEDI04_A** V003 in Earthdata Search, filter each polygon and time window, and download intersecting sub-orbit HDF5 granules and the separately supplied data dictionary. Sign in to download. For each valid beam retain `agbd`, `agbd_se`, `lat_lowestmode`, `lon_lowestmode`, `delta_time`, shot identifier and relevant V3 quality flags including `l4a_quality_flag_rel3`, `l2a_quality_flag_rel3`, `degrade_include_flag`, and predictor/response limit flags. Apply the V3 guide's application-specific quality guidance, then spatially filter individual footprints within the actual polygon; intersecting a granule alone does not guarantee useful shots inside it. Footprints are about 25 m and sparsely sampled, not a continuous raster. No observations were collected during instrument storage from March 2023 to April 2024. The [V3 user guide](https://daac.ornl.gov/GEDI/guides/GEDI_L4A_AGB_Density_V3.html) and [dataset record](https://daac.ornl.gov/cgi-bin/dsviewer.pl?ds_id=2508) differ in their stated end date; check returned granules for actual availability. A [September 2026 correction notice](https://forum.earthdata.nasa.gov/viewtopic.php?sid=0b41f8201315f730722430072a828c90&t=8261) concerns South American EBT/DBT models and says other strata are unaffected; track any revised release when reproducing results.
